## Следующий безопасный цикл наполнения

1. Сверить ранее переданные PDF (Бюджетный, Градостроительный, КАС, Земельный, Семейный, Лесной кодексы и Кодекс торгового мореплавания) с реальными файлами и SHA-256. Проверить также остальные загруженные PDF по перечню файлов, а не по названию беседы.
2. Для каждого акта сохранять реквизиты, URL первичного официального опубликования, хеш оригинала, дату получения, число страниц, способ извлечения, полноту и статус проверки.
3. Сверять изменения с официальным порталом https://pravo.gov.ru/ и отдельные даты вступления положений в силу. Не переносить дату последнего изменения на дату начала действия всех статей.
4. Добавлять новые тексты только в staging, проверять структурную полноту и соответствие оригиналу; после успешной локальной проверки переносить в `main`.
5. До независимой юридической проверки сохранять `verified=false`, не присваивать периоды действия без подтверждающих актов и не объявлять корпус полным.
6. Проверять локально `python scripts/validate_legal_data.py`, `python statute_corpus.py`, `python legal_evidence.py`, `python -m unittest discover -q`. GitHub Actions не запускать.

## Проверенные источники для дальнейшего сбора

- https://pravo.gov.ru/ — официальные публикации и эталонный банк правовой информации (это разные режимы).
- https://publication.pravo.gov.ru/ — первичные публикации, когда доступны.
- https://www.consultant.ru/ — справочная сверка редакций; не считать первичной публикацией.
