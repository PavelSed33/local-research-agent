## Получение первичных материалов

Выполнены точные поиски и запросы по делу А40-255028/2022. Новых оригиналов
нижестоящих актов не получено: публичная картотека вернула страницу проверки,
сайты судов — HTML-страницы без нужных полных актов. Адреса и результаты:
[CASE_REPORT_SOURCE_ATTEMPTS_2026-11-09.json](CASE_REPORT_SOURCE_ATTEMPTS_2026-11-09.json).

Это предусмотренный ТЗ исход при недоступности источников, а не успешная
загрузка судебной цепочки. Вторичные публикации, HTML и упоминания не были
превращены в первичные полные тексты. Архив остаётся прежним: семь PDF, 90 страниц.

Добавлены 11 дословных упоминаний из четырёх уже полученных определений ВС.
В отчёте видны конкретные суды, даты, цитаты и отсутствие отдельных карточек.
При наличии карточки на ту же дату это только кандидат для проверки: совпадение
даты не подтверждает суд, подлинность оригинала или смысл процессуальной связи.

## Открытая внешняя приёмка

| Проверка | Статус | Причина |
|---|---|---|
| Реальный браузер, взаимодействие и оформление | blocked | Chromium отсутствует; 10 сценариев Node VM не заменяют браузер |
| Запуск Docker | Не проверен | Docker отсутствует; тест упаковки проверяет только набор поставляемых файлов |
| Реальная внешняя модель | Не проверена | Нет необходимых настроек; сборка отчёта модель не использует |
| GitHub Actions | Отдельная инфраструктурная проверка | Предыдущие прогоны завершались до выделения runner; локальные проверки не объявляют CI зелёным |
| Приёмка юристом | Не выполнена | Нет независимой проверки профессиональным юристом; тестовые одобрения только в временных БД |

Функциональная часть ТЗ реализована и прошла указанные локальные проверки.
Без перечисленных внешних проверок не заявляется полная эксплуатационная
готовность. Полные истории законодательства и юридическое принятие 90 задач
не входили в двухчасовой этап и остаются отдельными работами.
