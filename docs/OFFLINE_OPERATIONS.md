# Работа и проверка без внешних сервисов — API 1.14

Все команды выполняются из корня проекта на Python 3.10+. Для перечисленных
проверок не нужны LLM/Tavily, браузер или Docker. Проверки используют локальный
HTTP и искусственные провайдеры; обращения к реальным сервисам не выполняются.

Прогон 8 ноября: 451 unit-тест, 26 HTTP-проверок и 4 примера запросов прошли;
15 контрольных ответов получили ожидаемые вердикты. Состав и ограничения:
[OFFLINE_AUDIT_2026-11-08.json](OFFLINE_AUDIT_2026-11-08.json).

## Проверка проекта

```sh
python -m unittest discover -q
python scripts/validate_legal_data.py
python scripts/audit_data.py
python scripts/evaluate_answers.py fixtures/response_quality_controls.json --control-suite
python scripts/acceptance.py
node scripts/test_document_input.cjs
```

`audit_data.py` проверяет ссылки между карточками, актами, источниками и
сценариями, дубликаты, интервалы дат, будущие даты получения и одинаковые
извлечения. Наличие текста не подтверждает полноту статьи или её действие
на дату ситуации. Статус `passed_with_gaps` означает отсутствие обнаруженных
структурных ошибок при сохранении перечисленных пробелов в доказательствах.

Контрольный набор содержит 15 синтетических ответов, в том числе намеренно
ошибочных. Успех `--control-suite` означает, что проверяющий код распознал
ожидаемые исходы, включая ошибки и блокировки. Это не 15 верных ответов модели.

## Попробовать локально

Запускать сервер на loopback без доступа из внешней сети:

```sh
API_HOST=127.0.0.1 python api.py
```

Адрес по умолчанию: `http://127.0.0.1:8080`. Если API_TOKEN уже настроен,
нужен обычный заголовок `Authorization: Bearer ...`; не помещайте токен в URL.
Примеры запросов находятся в `examples/offline_requests.json`, вымышленный
документ — `examples/offline_contract.txt`. Для локального извлечения через Python:

```sh
python - <<'PY'
import json
from doctext import read_document_path
from local_extract import handle_local_extract
document = read_document_path('examples/offline_contract.txt')
print(json.dumps(handle_local_extract({'document': document}), ensure_ascii=False, indent=2))
PY
```

`/extract/local` действительно работает без модели. Для `/review`, `/extract`
и навыков `demo:true` проверяет технический путь, а не анализирует правовые
риски. Анкеты `/privacy/check` и `/legal/research` могут запросить факты и
показать исследовательские карточки без внешних запросов.

## Документы и ссылки на фрагменты

Поддерживаются TXT UTF-8 (включая BOM) и DOCX. Максимальный файл — 10 МиБ,
разобранный текст — до 200000 символов. Неверную кодировку нужно исправить
пересохранением файла, а не подстановкой символов. PDF/OCR не поддерживаются.
Текст и DOCX нельзя передавать одновременно, даже если одно поле пустое.

При разборе DOCX сохраняются табуляции и ручные переносы строк. Таблицы
превращаются в последовательность абзацев: геометрия, нумерация страниц,
комментарии, колонтитулы и история правок не восстанавливаются. Исходный
DOCX никогда не следует считать полностью воспроизведённым плоским текстом.

`document_sha256` — SHA-256 UTF-8 разобранного текста после удаления внешних
пробелов. `document_span.start/end` — индексы Unicode в этом тексте, конец
исключён. Это не номера страниц или байтовые смещения DOCX. При повторении
цитаты указывается первое совпадение; `match_mode` различает точное
совпадение и совпадение с нормализацией пробелов. Для независимого
`/extract/local` прежние поля называются `text_sha256` и `span`.

## Ошибки и восстановление

| Код / HTTP | Что сделать |
|---|---|
| 400 | Проверить формат полей, размер, кодировку, наличие ровно одного документа. |
| 401 | Передать настроенный токен в Authorization. |
| `request_capacity` / 429 | Дождаться завершения текущих запросов и повторить с новым ID. |
| `duplicate_request_id` / 409 | Использовать новый X-Request-ID. |
| `request_cancelled` / 409 | Работа отменена; для нового запуска нужен новый ID. |
| `request_deadline` / 504 | Общий срок исчерпан; уменьшить задачу или проверить настройку тайм-аута. |
| `worker_protocol` / 500 | Рабочий процесс вернул некорректный формат; повторить с новым ID, при повторении сообщить разработчику код ошибки. |
| `skill_registry_unavailable` / 503 | Восстановить проверенную версию файлов навыков и манифеста. Не отключать проверку хешей. |
| `provider_error` / 502 | Рабочая модель/поиск недоступны либо ответ не прошёл проверки. Для локального технического примера использовать demo. |

## Хранение и границы защиты

По умолчанию HTTP-результаты не публикуются в постоянный каталог. Рабочий
каталог запроса удаляется после успеха, ошибки, дедлайна или отмены. Явное
сохранение отчётов и история сессий регулируются существующими настройками;
экспортированный пользователем JSON содержит данные документа.

HTTP-журнал содержит только код статуса, без URL, query string, заголовков,
текста документа и некорректной строки запроса. Ошибки проверки не повторяют
значения реквизитов, неизвестные категории модели или её произвольные URL.
Удаление временного файла не является гарантией стирания данных с диска;
копии ОС, резервные копии и инфраструктурные журналы находятся вне приложения.

Документ обозначен в промптах как недоверенные данные; код не принимает
модельные флаги юридической приёмки и отвергает выдуманные цитаты. Мок-тесты
проверяют эти границы, но не доказывают устойчивость реальной модели ко всем
вредоносным инструкциям и не устанавливают правильность юридического вывода.
