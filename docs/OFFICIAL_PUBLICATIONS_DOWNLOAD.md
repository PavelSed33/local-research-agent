# Официальные публикации: контролируемое получение

Источник: https://publication.pravo.gov.ru/ — официальный государственный портал.

`scripts/download_official_publications.py` принимает только конкретные номера электронного опубликования (eoNumber). Без флага `--execute` сетевые запросы не выполняются.

```bash
python scripts/download_official_publications.py --eo-number 0001202601010001
python scripts/download_official_publications.py --eo-number 0001202601010001 --execute
```

Номер выше иллюстративный и не подтверждён как существующий. Для реального запуска укажите номер из официальной карточки документа. Данные сохраняются отдельно в `data/official_publications_quarantine`; в GitHub их автоматически не загружают.

**Не выполнено:** массовая загрузка кодексов, подтверждение текущей редакции, проверка условий автоматизированной выгрузки, реальные интеграционные тесты на API, полная судебная база. Портал Минюста предоставляет бесплатный поиск, но это не подтверждает наличие открытого API для массовой выгрузки.

**Меры безопасности:** фиксированный HTTPS-хост, отказ от перенаправлений на чужой хост, ограничение 12 МБ на ответ и 20 документов за запуск, контроль SHA-256, явный запуск сети, карантин без подключения к /ask.

**Известные ограничения:** HTTP-переадресация на том же хосте допустима; Content-Type ответа текстового метода проверяется только на HTML. При неожиданном формате или ошибке источник остаётся непроверенным. Время получения и хеш не подтверждают юридическую актуальность.
