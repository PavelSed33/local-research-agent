# Приёмка полных текстов законодательства РФ — 2026-11-09

## Источники
1. https://www.pravo.gov.ru/ — официальное опубликование и раздел «Тексты правовых актов с внесёнными изменениями».
2. https://pravo.minjust.ru/ — информационные банки Минюста РФ.

**Важно:** опубликованный первоначальный акт, закон о поправках и консолидированная редакция — разные документы. Нельзя считать отдельный PDF поправки полной действующей редакцией кодекса.

## Порядок для каждого кодекса
1. Найти полный консолидированный текст и указать прямой URL конкретного документа, реквизиты закона и дату редакции.
2. Сохранить исходный файл без изменения; отдельно зафиксировать SHA-256 и дату получения.
3. Зарегистрировать локальный файл через `scripts/register_official_legal_text.py`. По умолчанию `approved_for_import=false`.
4. Сверить источник, полноту текста, изменения, дату вступления поправок в силу и переходные положения; задокументировать проверку.
5. Только после проверки прав использования и утверждения редакции изменить манифест для разрешённого импорта. Автоматически повышать `verified` нельзя.
6. Сверить извлечённые статьи и главы с эталонным перечнем для той же редакции; зафиксировать пропуски и отменённые статьи.

## Приоритетная очередь
- ГК РФ, части 1–4;
- НК РФ, части 1–2;
- ТК РФ, КоАП РФ, ГПК РФ, АПК РФ, КАС РФ, УК РФ, УПК РФ;
- остальные кодексы из `data/legal_code_inventory.example.json`.

## Текущий факт выполнения
Добавлен реестр и механизм приёмки, но **полные консолидированные тексты не загружены и действующие редакции не подтверждены**. Наличие URL портала не доказывает доступность машинного скачивания или право на массовое копирование. Для каждого документа нужен собственный проверяемый источник и результат сверки.
