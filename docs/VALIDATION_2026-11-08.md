Реальный Docker не запускался: исполняемый файл отсутствует. Внешние LLM/Tavily
не проверялись: отсутствуют LLM_API_KEY, LLM_MODEL и TAVILY_API_KEY. Конфигурация
не менялась, документы и секреты внешним провайдерам в рамках этих проверок не
отправлялись. Браузерная визуальная приёмка не выполнялась.

Оригинальные официальные публикации всех норм, полная история редакций и
переходных положений не подтверждены. Юридическая приёмка не пройдена.
Девяносто черновиков не имеют утверждённых юристом ответов. `verified=false`
и `period_supported=false` сохранены. Успешное выполнение GitHub Actions
отдельно не предполагается из локальных результатов.

## Дополнительная проверка среды и интерфейса

Исправлена загрузка каталога и анкет в разделе «Правовые сценарии»: ранее
поля существовали, но запрос к `/legal/research/options` и построение вопросов
в JS отсутствовали. При смене сценария ответы сбрасываются в «Неизвестно».
Браузерный сценарий расширен на все три навыка, недостающие факты, каталог
35 правовых сценариев и сброс ответов. Это подготовленные проверки: реальное
выполнение Chromium не состоялось.

`python scripts/browser_acceptance.py` запускает временный API с одноразовым
токеном и выполняет браузерный сценарий в отдельной группе процессов. Отсутствие
Node, Playwright или Chromium возвращает `blocked`, а не успешную приёмку.
Сбой или таймаут браузера возвращает `failed`; процессы и сервер очищаются.
При необходимости оператор может задать путь установленного Chromium через
`BROWSER_SMOKE_EXECUTABLE_PATH`. Приложение автоматически браузер не скачивает.

Фактический результат здесь: `blocked / chromium_missing`. Playwright установлен,
но загрузка Chromium вернула невалидный ZIP; установка системных пакетов
не удалась из-за ограничений setgroups/seteuid среды. Облачный браузер вернул
`ERR_HTTP_RESPONSE_CODE_FAILURE` при открытии локального API. Браузерная
и визуальная приёмка не пройдены.

Повторная демо HTTP-приёмка: 20/20. Проверка `--live` выполнила локальную часть,
затем вернула `blocked`: не заданы LLM_API_KEY, LLM_MODEL и TAVILY_API_KEY.
Docker отсутствует. Первичные публикации 156-ФЗ/519-ФЗ повторно не получены:
таймаут либо недоступность через веб-инструмент. Новых оригиналов ноль;
правовые статусы корпуса не повышались. Машиночитаемый отчёт:
`docs/RUNTIME_VERIFICATION_2026-11-08.json`.
