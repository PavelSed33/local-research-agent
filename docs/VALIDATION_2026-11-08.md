Проверены повреждение корпуса, хеши, подмена акта/URL, выход за каталог и
символические ссылки, точные номера статей, поздняя копия для исторической
ситуации, разделение профилей, отсутствие автоматической правовой квалификации,
локальность анкет и авторизация новых HTTP-маршрутов. Проверено сохранение
старой даты при неудачном обновлении и исключение редакционных вставок при
извлечении. Новые файлы включены в Dockerfile; тест комплектации импортирует
приложение и читает корпус из точного набора файлов образа.

Реальный Docker не запускался: исполняемый файл отсутствует. Внешние LLM/Tavily
не проверялись: отсутствуют LLM_API_KEY, LLM_MODEL и TAVILY_API_KEY. Конфигурация
не менялась, документы и секреты внешним провайдерам в рамках этих проверок не
отправлялись. Браузерная визуальная приёмка не выполнялась.

Оригинальные официальные публикации всех норм, полная история редакций и
переходных положений не подтверждены. Юридическая приёмка не пройдена.
Девяносто черновиков не имеют утверждённых юристом ответов. `verified=false`
и `period_supported=false` сохранены. Успешное выполнение GitHub Actions
отдельно не предполагается из локальных результатов.

## Объединение с управлением запросами

Расширение корпуса объединено с изменениями PR №23 (API 1.8): дедлайн,
отмена, изолированные рабочие процессы и защита истории удалённой сессии.
Разрешены пересечения API, интерфейса, реестров и проверки комплектации.
Потребительская переходная норма сохраняется при заполненном лимите пяти
источников; регрессия проверяет её соседство с текстом статьи и сохранение
первых двух свежих поисковых результатов. Точный хеш сохранённого извлечения
проверен без изменения ожидаемого значения в манифесте.

Повторная локальная HTTP-приёмка: 20/20; структурная оценка: 16/16.
Полный набор включает реальные локальные HTTP-проверки отмены и дедлайна
со специально задержанным синтетическим провайдером. Это не подтверждает
работу внешних LLM/Tavily. Все 454 нормативных извлечения и пять прочих
извлечений прошли проверки целостности; юридический статус не повышался.

Добавлены три закреплённых адаптера Awesome Legal Skills (API 1.9).
Проверены происхождение и лицензии, ошибки/подмена файлов, границы цитат,
флаги доверия, политика облачной передачи и отмена рабочего процесса навыка.
Описание: `docs/LEGAL_SKILLS.md`.
