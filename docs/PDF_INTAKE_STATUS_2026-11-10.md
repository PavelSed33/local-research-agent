## Ограничение и обязательные следующие шаги

1. Передать бинарные оригиналы в контролируемое хранилище. Коннектор GitHub умеет создавать текстовые файлы и Git-объекты, но не получает байты файлов из рабочего контейнера напрямую; локальный контейнер не имеет сетевого доступа к GitHub.
2. Проверить право на публикацию копий документов, экспортированных из КонсультантПлюс. При необходимости хранить только допустимые исходные нормативные тексты из официальных открытых источников и метаданные PDF.
3. Для каждого документа: provenance, полный SHA-256, номер, дата, редакция, начало действия, статус юридической верификации; удалить точные дубликаты.
4. Только после передачи оригиналов извлечь полный текст, разделить по статьям, создать индекс и провести проверку полноты и применимости.
5. Не менять `verified` и `history_complete` на `true` без подтверждённой проверки.

GitHub Actions для этой процедуры не нужны.
