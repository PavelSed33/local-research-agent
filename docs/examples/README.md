# Технический пример отчёта

[Отчёт по А40-255028/2022](case-report-a40-255028-2022.md) сформирован
API 1.21 из официального архивного PDF определения ВС РФ №305-ЭС23-19099.
Это точные UTF-8-байты экспорта без ручного редактирования.

Использована временная локальная БД. Идентификаторы дела, документов и карточек
служат только примером и не разрешаются в рабочей БД пользователя. Токены
и реальные пользовательские дела в файле отсутствуют.

Показаны одно загруженное определение и три упоминания нижестоящих актов
с цитатами исходного определения. Оригиналы этих трёх актов не загружены.
Юридическая приёмка, полнота истории и применимость не подтверждены.
