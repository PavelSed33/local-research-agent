## Состав интеграции

Сохранены только три исходных SKILL.md и соответствующие файлы лицензий.
Их Git blob SHA сверены с закреплёнными upstream-коммитами; SHA-256 всех
исходников, лицензий и русских адаптеров записаны в `skills/manifest.json`.
Атрибуция — `third_party/selected-skills/ATTRIBUTION.md`.
Код, shell-команды, MCP-коннекторы, архивы зависимостей и внешние скрипты
из этих репозиториев не импортировались.

Рантайм использует только локальные адаптеры. Лицензия, допустимые пути,
схема и размер реестра, отсутствие симлинков и контрольные суммы проверяются
до запуска. Обновление через пользовательский URL или HTTP загрузчик отсутствует.
Новые навыки используют модель без поискового сервиса; действуют авторизация,
дедлайн, отмена запроса и политика передачи документов облачной модели.

Каждый вывод привязан к найденной в документе цитате; модель не может
повысить `verified` или `lawyer_reviewed`. Это проверка наличия цитаты,
не доказательство правильности юридического вывода. Хронология остаётся
черновиком событий, поиск — планом; ни один из этих навыков не подтверждает
действующую редакцию права или полноту судебной практики.

## Проверка проекта

Добавлены регрессии для повреждённого реестра, HTTP 503 с сохранением
доступности health/OpenAPI, неоднозначного ввода документа, некорректного
типа приоритета модели и пробельных цитат playbook. Новые навыки проверяются
в demo без сети и с подставной моделью; проверяется отсутствие вызовов поиска.
Docker-набор файлов дополнен новыми исходниками и лицензиями; упаковочный
тест воспроизводит COPY в изолированном каталоге, без запуска Docker.
HTTP smoke расширен с 23 до 26 проверок; браузерный сценарий охватывает шесть
методик, но фактический запуск требует установленного Chromium.

Реальная модель, внешний поиск, браузер и Docker требуют отдельного прогона
в подготовленной среде. Юридическая приёмка синтетических кейсов не проведена.

Итоговый локальный прогон: **425 unit-тестов**, **26 HTTP-проверок**,
валидация корпуса и шести навыков, компиляция Python и синтаксис JavaScript —
успешно. Два синтетических снимка ответов прошли офлайн-проверку структуры
и цитат. Подробный состав и ограничения:
[AGENT_AUDIT_2026-11-08.json](AGENT_AUDIT_2026-11-08.json).
