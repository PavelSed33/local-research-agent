# Проверенные номера публикаций для пилотного запуска

Источники: официальные карточки на publication.pravo.gov.ru.

- `0001202411230024` — Федеральный закон от 23.11.2024 № 403-ФЗ, поправки, связанные с частью первой ГК РФ: https://publication.pravo.gov.ru/document/0001202411230024
- `0001202407220005` — Федеральный закон от 22.07.2024 № 190-ФЗ, изменения части четвёртой ГК РФ: https://publication.pravo.gov.ru/document/0001202407220005

**Важно:** это опубликованные законы о внесении изменений, а не полные актуальные редакции кодексов. Не маркировать как действующий консолидированный текст.

```bash
python scripts/download_official_publications.py --eo-number 0001202411230024 --eo-number 0001202407220005
python scripts/download_official_publications.py --eo-number 0001202411230024 --eo-number 0001202407220005 --execute
```

Проверка доступа к API из текущей рабочей среды не удалась из-за ошибки разрешения DNS. Команда с `--execute` **не была успешно выполнена**; скачанных PDF нет. Доступность endpoint и юридические условия массовой выгрузки требуют проверки в среде развёртывания.
