# Аудит полноты и редакций: начальная версия

Для локального карантинного корпуса используйте `scripts/audit_external_law_corpus.py`.

```bash
python scripts/audit_external_law_corpus.py --db data/external_law_quarantine.sqlite --inventory data/legal_code_inventory.example.json --date 2026-11-09 --output coverage.json
```

Это **предварительная проверка наличия по точному названию**, а не подтверждение полноты кодекса. Статус `verified_for_date` появляется только для записи с `verified=1` и явно указанным периодом действия. Сам скрипт не присваивает статус проверки, не извлекает статьи, не устанавливает даты вступления в силу и не сверяет тексты с официальной публикацией.

Следующие обязательные шаги: эталонный реестр всех действующих кодексов и статей с идентификаторами, адаптер метаданных RusLawOD, независимая проверка официальных публикаций, связь поправок с редакциями и тесты на пограничные даты. До завершения этих шагов нельзя использовать карантинные документы как подтверждённую правовую основу ответа.

Для RusLawOD полный набор данных опубликован отдельно в Parquet на Hugging Face; текущий импортёр Parquet не поддерживает. Данные не скачаны автоматически. Перед массовым скачиванием проверить условия использования, объём хранения и разрешённость применения.
