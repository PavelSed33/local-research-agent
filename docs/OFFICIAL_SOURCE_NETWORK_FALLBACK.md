# Официальные правовые тексты: обход сетевого ограничения

Проверка 2026-11-09: рабочая среда не разрешает DNS-имя `publication.pravo.gov.ru`; автоматическое скачивание здесь не состоялось.

1. На компьютере с обычным интернет-доступом запустить `python scripts/diagnose_official_law_access.py`. Если DNS и HTTPS доступны, открыть официальный портал `https://www.pravo.gov.ru/` и раздел «Тексты правовых актов с внесёнными изменениями».
2. Для каждого кодекса скачать **именно полный консолидированный текст**, а не только опубликованный закон о поправках. Проверить дату редакции, реквизиты, дату вступления изменений в силу и переходные положения.
3. Зарегистрировать локальный файл `python scripts/register_official_legal_text.py --file FILE.pdf --source-url URL --title TITLE --law-number NUMBER --edition-date YYYY-MM-DD --output manifest.json`.
4. Сохранить оригинал и манифест в защищённом хранилище. Не устанавливать `approved_for_import=true` без проверки источника, условий использования и юридической сверки. Для PDF нужен отдельный шаг извлечения текста: существующий XML/JSON/TXT импортёр PDF не принимает.
5. После утверждения подготовить текстовый файл и манифест с SHA-256 именно этого импортируемого файла, затем запускать импорт и структурный аудит.

**Нельзя** считать успешную DNS-проверку доказательством доступности API или разрешением на массовое скачивание. GitHub Actions не требуется для локальной процедуры.
