# ИИ-агент-исследователь

Локальный прототип, который принимает тему, формирует поисковые запросы, собирает материалы, готовит русскоязычный отчёт с цитатами и сохраняет журнал исследования.

## Возможности

- планирование до 5 поисковых запросов;
- поиск через Tavily и получение текста источников;
- удаление повторяющихся ссылок;
- подготовка отчёта на основе только найденных материалов;
- ссылки вида `[1]` и итоговый список источников;
- сохранение отчёта в Markdown и журнала в JSON;
- ограничение числа запросов и источников;
- демонстрационный режим без ключей и внешних запросов;
- запуск без сторонних Python-библиотек.

## Требования

- Python 3.10 или новее;
- для реального исследования — ключ языковой модели с OpenAI-совместимым API и ключ Tavily;
- для демонстрационного запуска ключи не нужны.

## Быстрая проверка

Откройте терминал в папке проекта и выполните:

```bash
python agent.py "Как развиваются ИИ-агенты" --demo
```

В Windows при необходимости используйте `py` вместо `python`.

Команда создаст папку `результаты` с двумя файлами:

- `отчёт-<дата>.md` — готовый отчёт;
- `журнал-<дата>.json` — запросы, источники и служебная информация.

Демонстрационный режим использует условные материалы и предназначен только для проверки работы программы.

## Настройка реального поиска

1. Скопируйте `.env.example` в `.env`.
2. В `.env` укажите:

```dotenv
LLM_API_KEY=ваш_ключ
LLM_MODEL=название_доступной_модели
LLM_BASE_URL=https://api.openai.com/v1
TAVILY_API_KEY=ваш_ключ_tavily
```

Если используется другой OpenAI-совместимый сервис, замените `LLM_BASE_URL` на его базовый адрес без `/chat/completions` в конце.

3. Запустите исследование:

```bash
python agent.py "Состояние рынка электромобилей в Европе" --queries 3 --sources 6
```

Параметры:

- `--queries` — от 1 до 5 поисковых запросов;
- `--sources` — от 1 до 10 источников в итоговом наборе;
- `--output-dir` — другая папка для результатов;
- `--demo` — локальная проверка без API.

Пример:

```bash
python agent.py "Новые подходы к хранению энергии" --queries 5 --sources 10 --output-dir мои_исследования
```

## Структура отчёта

1. Краткий вывод.
2. Основные факты.
3. Подробный анализ.
4. Противоречия и ограничения.
5. Выводы.
6. Источники.

## Тесты

```bash
python -m unittest -v
```

Тесты проверяют разбор ответов модели, удаление дублей, ограничения интерфейса и полный демонстрационный цикл. Они не обращаются к внешним сервисам.

## Ограничения прототипа

- Качество исследования зависит от найденных источников и выбранной модели.
- Агент не гарантирует истинность материалов; важные выводы нужно проверять по ссылкам.
- Некоторые страницы могут быть недоступны поисковому сервису.
- Нет графического интерфейса, долговременной памяти, PDF-экспорта и фоновых заданий.
- Файл `.env` содержит секреты: не публикуйте его и не добавляйте в систему контроля версий.

## Возможное развитие

После проверки качества можно добавить повторное исследование при недостатке данных, оценку надёжности источников, PDF-экспорт, историю запусков и веб-интерфейс.
