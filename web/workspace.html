Сохранённые документы
    

    

    Сопоставить документы
    По умолчанию рабочий анализ использует только локальную модель. Облако также требует разрешения на сервере.
    

    Подготовка документа
    Скрытие данных — предварительное; проверьте текст перед передачей. Экспорт создаёт простой DOCX без исходного оформления.
    

    Экспертная проверка материалов
    Требуется другая учётная запись с ролью эксперта и доступом к делу. Приложение не удостоверяет профессиональную квалификацию.
    

    Полный ответ API
    

    Экспертная приёмка редакций, судебных связей и эталонов выполняется отдельно через защищённый API.
