Сохранённые документы
    

    Подготовить редакцию нормы

    Выберите сохранённый официальный источник и полный текст нужной нормы. Новый материал остаётся черновиком до независимой экспертной проверки.
    

    










    

    Дата получения файла не подтверждает действие нормы. Исторические карточки без точной цитаты требуют нового досье и новой проверки для пилота.
    

    

    Сопоставить документы
    Сервер выберет единственную редакцию на указанную дату. При пробеле или пересечении периодов анализ остановится.
    Пилот: договор услуг между предпринимателями
    В контекст включается весь выбранный текст до 20000 символов. Укажите дату и выберите необходимые редакции норм выше. Список договоров обновляется вместе с документами дела.
    Это заявления пользователя. Квалификация, применимость источников и полнота проверки требуют участия юриста.
    По умолчанию рабочий анализ использует только локальную модель. Облако также требует разрешения на сервере.
    

    Подготовка документа
    Скрытие данных — предварительное; проверьте текст перед передачей. Экспорт создаёт простой DOCX без исходного оформления.
    

    Позиции и связи судебных актов
    Дополнения сохраняются как новая версия без переноса одобрения. Ссылка на другой акт требует его отдельной карточки и точной цитаты с номером дела и датой. Приложение не удостоверяет правовой смысл связи.

        Отчёт для проверки юристом
        В отчёт попадут только загруженные карточки на выбранную дату. Полнота истории, применимость и квалификация проверяющих не подтверждены. Цитаты могут содержать данные дела.
        Предпросмотр того же файла
        

        История включает только загруженные карточки. Отмена с направлением на новое рассмотрение не означает окончательный выигрыш.
        

        Задания для юридической приёмки
        Это синтетические задачи без принятых ответов. Ответ вводит эксперт; затем материал проверяет другой участник. Квалификация пользователей отдельно не удостоверяется.
        Цитат: 0
        Оценить ответ по принятому эталону
        Оценку записывает пользователь с ролью эксперта. Нужен открытый эталон с действующим одобрением. Вставленный ответ сохраняется в базе дела; не добавляйте ключи и посторонние данные.
        Отметьте пропущенные существенные риски:
        Сравнение возможно на общих эталонах. Средние по разным наборам задач не доказывают, что версия лучше. Квалификация проверяющих и факт реального запуска модели отдельно не удостоверяются.
        

        Правки в исходном Word
        Сохраняется пакет исходного DOCX; явные замены оформляются как вставки и удаления Word. Таблицы, стили, колонтитулы и изображения сохраняются. Вставленный текст наследует оформление начала заменяемой цитаты; страницы могут измениться.
          Существующие исправления нужно сначала принять или отклонить в Word. Цитаты внутри полей, ссылок, закладок и сложных блоков не редактируются. Макросы, вложенные объекты и подписанные пакеты отклоняются. Метаданные, комментарии и разрешённые гиперссылки исходника сохраняются — это не обезличивание.
          

          Экспертная проверка материалов
          Требуется другая учётная запись с ролью эксперта и доступом к делу. Приложение не удостоверяет профессиональную квалификацию.
          

          Полный ответ API
          

          Экспертная приёмка редакций, судебных связей и эталонов выполняется отдельно через защищённый API.
